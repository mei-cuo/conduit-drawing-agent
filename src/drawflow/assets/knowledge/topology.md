# 管井、设备与拓扑

## 实体类型
名称包含人孔、手孔、接头管箱时识别为管井。类型依次取自名称关键词、图例匹配、形状：圆形对应人孔，正方形对应手孔。纯桩号标签结合引线图例确定对象，留存图例依据和复核事项。摄像机、交通调查站和纯编号设施作为设备独立处理。

## 直通与分歧
人孔、手孔和接头管箱描述实体类型；直通、分歧描述连通类型。名称直接出现直通或分歧时优先使用名称。沿主线方向连接前后两个邻井仍可为直通。分歧需要小范围内连接至少两个已记录管井并存在离开主线的支路。邻井 ID 必须真实存在，连接不能指向自身。

## 设备关联
优先读取局部文本，随后核对实际连接线。只有空间邻近时记录疑似关联和人工复核事项。明确没有设备关联时设备字段填空字符串；关联未知时相应字段填无法判断。线条交叉与实体连接分别判断。
