# 标注组、表格和导出

## 一标多井
同一处完整标注对应多个实际符号时赋予共享 group_id，按从左到右命名。桥梁两端电力手孔×3 可导出桥梁两端电力手孔-1、桥梁两端电力手孔-2、桥梁两端电力手孔-3；raw_name 保留完整原文。不同标注组独立编号，同页同名标注不共用序列。

## 表格对应
先找到图上的实际符号与编号，再沿引线确认底部表格对应列，最后读取该列桩号、类型和用途。中墩两侧、开口两侧描述位置，具体实体类型需结合图例。一个编号可能对应多个真实符号时分别建对象，并记录复核原因。

## 字段规范
最终文件为 16 字段 JSON 数组。未知值填无法判断，不适用填空字符串。页号取印刷页号；所属路段取标题栏，其次底部图名栏。跨页和边缘截断在备注中描述。输出记录与 evidence.json、audit.json 通过 object_id 和 run_id 关联。
