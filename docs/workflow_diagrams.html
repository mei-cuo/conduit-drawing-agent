图纸识别项目工作流

一套实现：LangChain 组织模型消息与结构化输出，LangGraph 管理节点、分支、修复和复核恢复。

统一识别流程

源码：src/conduit/workflow.py；入口：scripts/run.py

API 模式可带反馈重新调用模型；文件响应模式将自动修复次数设为 0，已有观察不会被重复读取来冒充新的识别。

子智能体如何接入

导出 agent_request.json → 子智能体读取图纸、OCR 与规则 → 写入 agent_response.json → 工作流校验摘要并读取响应。

交接目录：outputs/agent-handoff/；应用本身不自动启动 Codex 子智能体。图中虚线表示观察结果输入。
